# Дневник тренировок

Минималистичное приложение (PWA) для ведения дневника силовых тренировок и отслеживания прогресса. Сделано под Android (Xiaomi 14 / HyperOS), работает офлайн, данные хранятся только на телефоне.

## Возможности

- **Сегодня** — запись тренировки: упражнение → подходы (вес × повторения). Подсказка «прошлый раз» и автоподстановка последнего веса.
- **История** — все тренировки, общий объём, кнопка «Повторить» (скопировать тренировку в сегодняшнюю).
- **Прогресс** — график по каждому упражнению: расчётный 1ПМ (формула Эпли), максимальный вес, объём.
- **Claude** — анализ тренировок через вашу подписку **Claude Pro**:
  - «Отправить в приложение Claude» — открывает системное меню «Поделиться», выберите **Claude**: запрос с вашим дневником откроется в приложении Claude.
  - «Открыть в claude.ai» — открывает новый чат с уже вставленным запросом.
  - «Скопировать запрос» — на случай, если удобнее вставить вручную.
- Экспорт / импорт резервной копии в JSON.

> Почему не через API: подписка Claude Pro не даёт API-ключа (API оплачивается отдельно). Поэтому приложение передаёт данные в официальное приложение Claude — анализ идёт в рамках вашей подписки, никаких ключей хранить не нужно.

## Установка на телефон

1. Опубликуйте папку как статический сайт. Проще всего — GitHub Pages:
   *Settings → Pages → Source: Deploy from a branch → `main` / `(root)`*.
   Сайт появится по адресу `https://<user>.github.io/<repo>/`.
2. Откройте ссылку в **Chrome** на телефоне.
3. Меню ⋮ → **«Добавить на главный экран» / «Установить приложение»**.

Приложение откроется во весь экран, как обычное, и будет работать без интернета.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
